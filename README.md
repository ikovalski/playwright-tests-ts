Задание 1
Перед началом этого задания необходимо установить desktop приложение Docker
1. Создать новый репозиторий в github с названием playwright-tests-ts (можно через git clone / git init)
2. От главной ветки (main) создать ветку pw-basics
3. Перейти в ветку pw-basics
4. Добавить файл .gitignore и добавить туда node_modules
5. Создать проект через npm init
6. Установить playwright
7. Добавить Dockerfile и docker образ (image)
8. Написать 1 UI тест для сайта https://www.saucedemo.com/v1/ (как мы обсуждали на занятии)
9. Написать 1 тест с использованием Codegen
10. Добавить скрипт в package.json для запуска тестов через npm
11. Запушить изменения в github
12. Создать pull request в ветку main
